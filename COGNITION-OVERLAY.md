# Cognitive overlay

This fork adds a cognitive layer to every skill in `skills/` without changing
the SDLC engine.

- Each `skills/<name>/SKILL.md` is the upstream file plus one line,
  `Read COGNITION.md.`, directly after the frontmatter.
- Each `skills/<name>/COGNITION.md` holds five blocks: Role & Anti-Sycophancy,
  Delimiters & S2A, Cognitive Protocols, Dependencies, Output Contract. Techniques
  are adapted from [The Prompt Report](https://arxiv.org/abs/2406.06608v6).
- All other upstream files (references, agents, fixtures, scripts) are unchanged.
- Five core skills (`om-auto-write-spec`, `om-auto-implement-spec`,
  `om-auto-fix-issue`, `om-auto-review-pr`, `om-auto-qa-pr`) have hand-audited
  layers. The other 69 are generated by `scripts/cognition/build_cognition.py`
  from a category and a skill-specific focus sentence.
- Two skills (`om-auto-continue-pr`, `om-auto-merge-buddy`) had blank lines
  before headings removed so the loader fits the 20000-character body budget
  enforced by `scripts/lint.sh`. No instruction text changed.

Check with `python scripts/validate-cognition.py` (compares against the pinned
upstream commit via git) and `bash scripts/lint.sh`.

Limits: byte preservation and lint do not show that models behave better or resist
prompt injection. The delimiters and S2A text are adaptations, not a proven defense.
